# Контрольные вопросы 
1. Python: выполняет код построчно, ошибку видит только когда дойдет до проблемной строки, а C#: сначала компилирует весь код. Если есть синтаксическая ошибка, программа вообще не запустится
2. Состоит из двух шагов: 1. Build (компиляция .cs файлов). 2. Запуск получившейся программы.
3. Это результат работы компилятора(готовая программа и временные файлы),а не исходный код. Они создаются заново при каждом запуске, поэтому их не хранят в Git
4. commit — сохраняет изменения локально на компьютере,а push — отправляет эти сохранения на GitHub.
5. + - просто склеивает,но с большим количеством переменных код становится нечитаемым.$""- вставляет пременные прямо в текст. Предпочительнее,потому что нагляднее и чище.
6. Дробная часть отбрасывается(не округляется).Как исправить: Привести один из операндов к double (например, (double)a / b).
7. const задается один раз и не может быть изменена в программе. Пример: const double VatRate = 0.20; (ставка налога, которую нельзя менять).
8. 1.Top-level: упрощенный синтаксис (C#9). Позволяет писать код сразу, без лишних class и Main. Компилятор достраивает всё сам.
2.Классический: требует вручную создавать класс и метод Main.
